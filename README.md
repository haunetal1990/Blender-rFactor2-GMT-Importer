# Blender rFactor 2 GMT Importer

This plugin allows you to import GMT files from the racing game **rFactor 2** directly into Blender. It supports importing track and car models, including their associated materials, Billboards etc.

## Features

| Feature | Status |
|:---|:---|
| GMT 3D Models Import (Tracks & Cars) | ✅ |
| Billboard Mesh | ✅ |
| Material Import | ✅ |

---

Dieses Plugin ermöglicht den Import von GMT Dateien aus dem Rennspiel **rFactor 2** direkt in Blender. Es unterstützt den Import von Strecken- und Fahrzeugmodellen inklusive der dazugehörigen Materialien, Billboards usw.
